# 英语小星球

《剑桥国际少儿英语》第二版第 2 级的 12 单元学习伴侣，iPad 优先，同时支持手机与电脑。按外研社官方目录组织课程，提供官方资源入口、本机教材文字与音频导入、单词短语认读与听写、句子跟读、错题复习和学习进度。

这是独立学习工具，不是出版社官方产品。没有内置整册课文、词句表或原版录音；原版内容通过官方入口使用，或由用户在当前浏览器导入。应用不将教材和学习记录上传到服务器或公开仓库，系统朗读明确标注，不冒充原版录音。

## 运行与验证

Node.js 22.16+。`npm ci` 安装开发依赖；`npm test` 执行数据、导入、安全边界与进度测试；`npm run build` 构建 `dist/`；`npm start` 预览 http://127.0.0.1:4182/little-english/；`npm run test:browser` 验证主要流程、iPad 横竖屏、手机和 PC。默认浏览器为本机 Chrome，可用 BROWSER_EXECUTABLE 覆盖。

## 教材与本机数据

- 官方资源：https://kb.unischool.cn/ ，各单元链接使用 https://www.unischool.cn/kb/resource/kb2/book2/unit1/ 至 unit12/。
- 官方目录核对日期：2026-11-15；仅核对目录与资源入口，不声称已经逐字核对整册教材。
- 可直接添加词句，或导入 JSON / UTF-8 TSV（表格制表符分隔）。格式详见应用“学习资料”中的说明和可下载模板。导入先预览，按单元、类型和英文内容合并，不删除已有记录。
- 教材文字与进度存于 localStorage，音频文件存于 IndexedDB；无账号、不跨设备自动同步。清理浏览器数据会丢失记录。文字/进度支持导出 JSON；音频保留原文件，迁移设备需重新导入。
- 音频通过文件名绑定，支持可选起止秒数、播放速度与循环。未导入录音时可选择设备英语语音；没有可用语音时显示恢复提示。
- 不承诺首次离线打开、设备语音可用性或官方站点的持续可访问性；官方资源的账号/激活要求由出版社决定，应用不绕过权限。
- 图标原稿 `public/assets/logo.svg`，构建生成 favicon、180/192/512px PNG。支持添加主屏幕，未作真机验证。
