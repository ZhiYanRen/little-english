# Kids Box companion implementation plan

> Execute inline in this session with superpowers:executing-plans. User asked to proceed directly; no approval gate. Work on main per AGENTS.md.

Goal: deliver a static, source-backed 12-unit companion with private local materials and audio.
Architecture: browser ES modules; localStorage for validated text/progress; IndexedDB for audio. Static build copies public/ and generates icons with sharp.
Tech stack: HTML, CSS, JavaScript; Node test runner and Playwright for development.
Spec: docs/superpowers/specs/2026-11-15-kids-box-design.md

## Global constraints

No backend; no republishing textbook/audio; no fabricated textbook content; main only; Pages subpath; preserve other projects' dirty changes.

## Review focus

Untrusted imports and prototype properties; corrupt/blocked local storage; duplicate imports and progress merge; audio missing/stale playback; navigation/focus/reduced motion across screen sizes.
